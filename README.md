# XiXiCare

XiXiCare 是一款面向婴幼儿家庭的 Android 日常照护记录应用。它将喂养、睡眠、尿布、体征、成长趋势和育儿阶段信息集中在一个安静、简洁的界面中，帮助照护者快速记录，也能在需要回顾时清楚地找到每一次变化。

项目坚持本地优先：宝宝资料、日常记录和设置保存在设备中，核心功能无需注册账号，也不依赖云端服务。

## 主要功能

### 日常记录大盘

- 记录母乳、奶瓶和辅食，自动记忆上次使用的喂养方式与奶量。
- 分别记录左右侧母乳喂养时长，并提供常用时长快捷选项。
- 记录睡眠起止时间并自动计算时长。
- 记录尿布状态，包括嘘嘘、便便及便便颜色。
- 记录体重、身高和头围等成长数据。
- 快捷时长可按“当前时间为开始”或“当前时间为结束”推断。

### 时间轴

- 按时间查看所有照护记录。
- 支持按喂养、睡眠、尿布和体征类型筛选。
- 喂养记录显示距离上一次喂养的时间，方便掌握日常节奏。
- 支持编辑和删除已有记录。

### 喂养指南

- 根据宝宝月龄自动展示对应阶段的喂养建议。
- 提供辅食添加与常见过敏原排查清单，可手动标记排查状态。
- 展示分阶段疫苗接种建议，并可标记是否已接种。
- 指南内容用于日常参考，实际喂养与接种安排应遵循医生和当地卫生机构建议。

### 成长统计

- 汇总喂养次数、睡眠时长和成长体征。
- 按日、月、年等范围查看趋势。
- 图表仅依据实际记录的数据点绘制，并根据范围自动调整坐标间距。
- 出生体重可纳入出生月和跨年度趋势，便于观察完整成长过程。

### 睡眠声音

- 提供环境声音与纯音乐两类声音包，包括鸟鸣、雨声、海浪、安抚嘘声和轻柔器乐等。
- 声音包按需下载、独立保存，可同时下载、取消下载或随时删除。
- 支持单曲循环、同类型列表循环和播放一次。
- 支持睡眠定时、后台连续播放以及添加并重命名本地音频。

### 多宝宝与数据管理

- 支持添加和切换多个宝宝，每位宝宝拥有独立资料、偏好和记录。
- 支持浅色与深色模式，并适配手机、宽屏手机和折叠屏。
- 通过 XLSX 文件完整导入或导出宝宝资料、日常记录、疫苗、过敏排查和应用设置。
- 支持应用内检查更新、查看更新内容、直接下载并安装新版本。

### 加密云存档

- 使用 6 位存档码和宝宝生日，在多台设备间同步宝宝资料、日常记录、疫苗及过敏排查数据。
- 存档在设备端加密后上传，云端仅保存密文，无法直接查看记录内容。
- 支持自动合并、删除标记、失败重试及无变化快速校验，减少流量和重复请求。
- 自动同步默认关闭，可由用户主动开启；关闭时不会主动上传、拉取或变更本地数据，仍可手动操作云存档。

## 关于项目

XiXiCare 是一个由单人借助 AI 完整打造的开源项目。从需求梳理、交互与视觉设计，到前端实现、Android 原生能力、测试、打包和版本发布，整个过程均由一位开发者与 AI 协作完成。

它不是大型团队或商业产品的包装，而是从真实育儿记录需求出发持续打磨的小项目。AI 参与了整个创造过程，但功能取舍、体验判断和每个版本的最终决定始终由开发者独立负责。

## 隐私与说明

- 核心照护数据默认保存在用户自己的设备上。
- 云存档为可选功能，开启后上传的内容会先在本机完成加密。
- 删除应用或清除应用数据前，建议先在设置中导出完整备份。
- 本应用不替代医生诊断，涉及喂养、过敏、疫苗和生长发育的问题，请咨询专业医护人员。
