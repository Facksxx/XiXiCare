# XIXI CARE 微信小程序版

这是一个独立于 Android、iOS 主工程的原生微信小程序版本，不包含检查更新或应用安装功能。

## 已实现

- 多宝宝创建、编辑与切换
- 母乳亲喂、奶瓶、辅食、睡眠、尿布和体征记录
- 奶瓶喂养量与喂养方式按宝宝记忆
- 时间轴分类、删除记录与距上次喂养时间
- 喂养指南、疫苗接种标记与过敏排查
- 7 天、30 天和 1 年成长统计
- 睡眠声音在线播放、后台音频、单曲下载和取消下载
- 全部业务数据 JSON 导出、合并导入与覆盖导入
- 明暗主题、联系作者

## 导入工程

1. 在微信公众平台注册小程序并取得 AppID。
2. 用微信开发者工具导入此文件夹。
3. 将 `project.config.json` 中的 `touristappid` 替换为真实 AppID。
4. 在小程序后台配置声音文件最终请求涉及的 HTTPS 合法域名。
5. 提交正式版前，为 `requiredBackgroundModes: ["audio"]` 准备实际使用场景说明并完成审核。

当前机器未安装微信开发者工具，因此本版本完成了代码和配置静态检查，但仍需在开发者工具及真机上进行最终编译、域名和后台播放验证。

## 与 Android 版的差异

- 小程序由微信管理版本升级，不能自行检测、下载或安装 APK，因此按需求完全移除了更新功能。
- 业务数据默认保存在微信本地缓存中，不会自动跨设备同步。要跨设备同步需要新增服务器或微信云开发。
- 本地键值缓存容量有限，不适合保存大量图片或长期增长的海量记录；建议定期导出备份。
- 无法提供 Android 式任意目录选择和导出目录提示。备份通过微信文件分享导出，导入从聊天文件中选择 JSON。
- 无法访问手机完整文件系统。用户自定义音频只能从微信允许的临时文件来源选择，并受沙箱和文件配额限制；本版本先提供内置曲目下载。
- 后台音频必须经过平台审核。进入后台后，页面计时更新和多数 JS 操作会暂停，播放由微信后台音频能力接管。
- 网络请求和下载必须使用后台配置的 HTTPS 合法域名；进入后台后普通下载可能被系统中断。
- 下载的声音属于小程序沙箱文件，可能因用户清理微信缓存或删除小程序而消失。
- 不能实现 Android 前台服务、系统级常驻通知、任意锁屏控制以及完整的原生文件管理体验。

## 数据说明

所有宝宝、记录、疫苗、过敏排查和偏好均包含在 JSON 备份中。声音文件不写入备份，恢复后可重新下载。
